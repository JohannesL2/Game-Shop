# LevelUp Game Shop

<img width="800" alt="levelupstore-video" src="https://github.com/user-attachments/assets/56eb0172-b261-4101-a223-0094b6ec712c" />


A dynamic e-commerce platform for video games, built with **React** and powered by the **RAWG Video Games Database API**. The application features a robust backend integration using **Firebase** for data management and user experience.



## Live Demo

[levelupgameshop.netlify.app](https://levelupgameshop.netlify.app/)



## Key Features



- **Real-time Data Fetching:** Integrates with the RAWG API to display thousands of titles with up-to-date ratings, genres, and screenshots.

- **Firebase Integration:** Utilizes Firebase for seamless data persistence and potential user authentication.

- **Advanced Filtering:** Users can browse and filter games by platform, category, or release date.

- **Shopping Experience:** Includes a functional cart system to manage game selections and simulate a checkout flow.

- **Responsive UI:** Fully optimized for all screen sizes, ensuring a great experience on mobile, tablet, and desktop.



## Technology Stack



- **Frontend:** React.js (Hooks, Context API/State Management)

- **Backend/Database:** Firebase (Firestore)

- **Styling:** CSS / Tailwind CSS

- **Deployment:** Netlify

- **External API:** [RAWG Video Games Database](https://rawg.io/apidocs)
